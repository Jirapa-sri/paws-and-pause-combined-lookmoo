# Farm assets (Tiny Farm Pack + TFP anim)

Free pixel farm art used by Sunny Farm:

- **Tiny Farm Pack** — crops, dirt, barns, well, fence, animals, tool icons  
- **TFP_anim_v2** — hoe / watering-can character animations (Char1)

## Paths

| Path | Use |
|------|-----|
| `tiny/Other/Sprouts_Fruit_Crops.png` | Crop growth + harvest icons |
| `tiny/Other/Barns.png` | Farm map icon + interior barns |
| `tiny/Other/WaterWell.png` | Animated well |
| `tiny/Other/Tool_Icons.png` | Farm hub plant/water buttons |
| `tiny/Animals/*` | Chickens, cows in farm interior |
| `anim/Char1/*` | Optional tool anim sheets |

See `atlas.json` for crop row/column mapping.
